# Terraform Applied

**Oktatókönyv és nyelvi referencia – az alapoktól a haladó szintig**

A **Terraform Applied** egy magyar nyelvű, önálló tanulásra készült oktatókönyv és gyakorlati referencia az Infrastructure as Code (IaC), a Terraform és a HashiCorp Configuration Language (HCL) világához.

A célja, hogy az olvasó az alapfogalmaktól indulva fokozatosan jusson el a valós projektekben használható, biztonságos és jól karbantartható Terraform-konfigurációk megtervezéséig és felépítéséig.

## Miről szól?

A könyv többek között az alábbi témákat dolgozza fel:

- az Infrastructure as Code alapelvei és a Terraform működése;
- a Terraform CLI, a fejlesztői környezet és a projektstruktúra;
- a HCL szintaxisa, típusai, kifejezései és beépített függvényei;
- változók, lokális értékek, kimenetek, hivatkozások és függőségek;
- feltételek, ciklusok és dinamikus konfigurációk;
- providerek, erőforrások, adatforrások és modulok;
- workspaces, state-kezelés és backends;
- biztonság, tesztelés, kódminőség és hibakeresés;
- összetett, gyakorlati Terraform-projekt.

A példák platformfüggetlen szemléletet követnek, és szükség szerint AWS-, Azure-, Google Cloud- és OCI-környezeteket is bemutatnak.

## Hogyan épül fel?

A könyv 7 tematikus részből, 22 fejezetből és 10 függelékből áll. A fejezetek elméleti magyarázatokat, HCL-példákat, részletes kódelemzéseket, gyakori hibákat és megoldásokkal ellátott gyakorlófeladatokat tartalmaznak.

A magyarázatok magyarul készülnek, miközben a Terraform és az infrastruktúra-automatizálás bevett angol szakkifejezéseit megtartják, és első előfordulásukkor értelmezik.
