# Projektmemória – útmutató

Ez a könyvtár a Terraform Applied tartós, verziókezelt munkakontextusa. Nem beszélgetés-átirat, hanem a jóváhagyott célok, szabályok, döntések és aktuális állapot összefoglalója.

## Munkamenet elején olvasd el
1. PROJECT_CONTEXT.md és CURRENT_STATE.md
2. BOOK_STRUCTURE.md
3. EDITORIAL_GUIDELINES.md és TERMINOLOGY.md
4. A feladathoz kapcsolódó TECHNICAL_STANDARDS.md, VERSIONING.md és GITHUB_WORKFLOW.md

## Frissítési szabály
Minden érdemi munka előtt ellenőrizd a GitHub main ágon lévő memóriafájlokat és az aktuális PR-eket. Jelentős döntés után frissítsd a DECISION_LOG.md-ot; PR vagy kiadás után a CURRENT_STATE.md-ot. Eltérés esetén a repository legfrissebb, jóváhagyott állapota az irányadó. Ne halmozz elavult információt.

Ne tárolj jelszót, tokent, API-kulcsot, személyes azonosítót vagy szükségtelen személyes adatot.
